# Zupkeep site prototype

Open index.html in a browser. No build step, no dependencies.

- index.html            Homepage (15 sections)
- pages/utilities.html  Utility setup page with the lead form
- pages/dallas.html     City page template (Dallas)
- css/variables.css     Design tokens. Change colors and fonts here only
- css/global.css        Base type and layout
- css/components.css    Buttons, cards, forms, header, footer
- css/responsive.css    Tablet and mobile layouts
- js/main.js            Menu, FAQ, reveal, CTA tracking, form handling

Before launch
- Replace the text wordmark with the real logo file.
- Replace every .photo placeholder with real photography.
- Add real bios and testimonials (marked "Needs input").
- Set data-endpoint on the form, or rebuild it in Wix Forms / GoHighLevel.
- Confirm Privacy, Terms and Cancellation URLs in the footer.
